# BakaBoost

Complete BakaBoost site: marketing landing plus working in-app flows (explore, creator pages, shop, gifts, signup, dashboard). Vanilla HTML / CSS / JS. No build step.

## Run
Open `index.html`, or serve the folder:

```
npx serve .
python -m http.server
```

## What’s included
- Landing page (hero, why, how it works, features, storefront, studio, FAQ)
- Original images in `assets/` (hero, avatars, post)
- Explore, how it works, pricing, safety
- Creator pages, gift/boost checkout, signup/login
- Creator dashboard and supporter account (sample data in memory)

Reload resets sample state. Fees and creators are demo data.
